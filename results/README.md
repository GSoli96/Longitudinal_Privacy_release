# Aggregated results

Every file here holds **aggregate numbers only** (per case, per exposure
step, per judge, per detector). There are no per-person rows and no names.
Cases are identified by the internal letters A-H used throughout the paper.

All files are regenerated by:

```bash
python scripts/compute_stats.py --audit-root data/private/audit --out results
```

See `CONSISTENCY.md` for the comparison of every value against the paper.

## Files and provenance

| File | Content | Computed from |
|------|---------|---------------|
| `caseX_metrics.json` | per case: global metrics, per-step metrics, per-judge metrics, PES (both conditions) | the three per-judge audit files of case X, merged by majority vote |
| `rq1_global.csv` | global majority-vote metrics per case (`tab:rq1-global`) | the per-case majority vote |
| `rq1_per_step.csv` | DIR, hallucination, IQS, explicitness per exposure step per case (Appendix A) | the per-case majority vote |
| `rq1_pes_per_step.csv` | cumulative PES per step per case, under both PES conditions (`fig:rq1-pes`) | the per-case majority vote |
| `rq2_judges.csv` | per-judge global metrics per case (`tab:rq2-judges`) | each judge's audit file |
| `rq4_generated_classical_f1.csv` | classical-classifier F1 on the generated corpus (`tab:rq4-generated`) | each case's detection run on its generated corpus |
| `rq4_benchmark_ceas08_f1.csv` | classical-classifier F1 on the CEAS_08 benchmark (`tab:rq4-ceas`) | each case's detection run on CEAS_08 |
| `rq4_generated_llm_f1.csv` | LLM zero-/few-shot F1 on the generated corpus (`tab:rq4-llm`) | each case's LLM-detector run |

### How the source files map to these results

`compute_stats.py` reads, per case `<X>`, the judges' audit files from
`<audit-root>/<X>/judges/*.json` and the detection CSVs from
`<audit-root>/<X>/detection/`. In the original research repository these
correspond to each case's `llm_audit/` (or the per-judge `*_audit_results*`
files) and `training_results/` outputs. The mapping from those private
locations to the case letters is kept outside this public repository.

## PES

`caseX_metrics.json` records the cumulative PES curve and the final-step
distribution (mean / median / max) under **both** counting conditions:

- `pes.paper_text` — the paper's definition, `P and C and R and not E`
  (canonical; used in `rq1_pes_per_step.csv` column `pes_paper_text`);
- `pes.as_reported` — the original code's `P and C and R and E`, which
  reproduces the first-version (corrected) published values.

See `CONSISTENCY.md` for the correction history.

## What is not here

Per-person attribute lists, generated messages, raw documents and anything
that could identify an individual or an administration are **not** included.
They will only be released, in anonymised form, if and when
`docs/ANONYMISATION.md` allows it.
